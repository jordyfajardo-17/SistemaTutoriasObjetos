# SistemaTutoriasObjetos

Sistema de gestión de tutorías desarrollado para la Actividad 5 de Diseño de Software.

## Objetivo

Diseñar e implementar un modelo orientado a objetos para gestionar estudiantes, docentes, disponibilidad, reservas y comunicación de eventos de tutoría.

## Tecnologías

- Java
- Maven
- JUnit 5
- PlantUML

## Estructura

El proyecto separará el dominio, los servicios y las notificaciones para mantener alta cohesión y bajo acoplamiento.

## Ejecución

```bash
mvn clean compile
```

Las pruebas se ejecutarán con:

```bash
mvn clean test
```

## Declaración de uso de IA

Se utilizó inteligencia artificial como apoyo durante el desarrollo. El código y las decisiones de diseño serán revisados, adaptados y comprendidos por el estudiante antes de la entrega.
